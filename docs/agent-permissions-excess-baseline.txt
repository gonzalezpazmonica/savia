# Agent permission excess baseline (TRANSIENT) — scripts/validate-agent-permissions.sh
# One entry per line: "agent tool owner expires(YYYY-MM-DD)". A tool above the
# agent's permission_level (docs/rules/domain/agent-permission-levels.md)
# pending an operator decision (raise the level or drop the tool).
# Every entry has an owner and an expiry date: after it the entry stops
# absorbing the excess and the validator fails. An entry without owner or date
# fails too. The list may only SHRINK: a pair that is no longer an excess fails
# as stale, and tests/test-validate-agent-permissions-excess.bats caps the
# number of entries. Never add a pair to make CI green.
# Ordered by impact: Bash, Write, Edit, Task, Skill (effectful tools first).
